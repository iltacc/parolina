# Parolina – password in italiano

Web app per iPhone che genera password casuali, facili da pronunciare, con parole italiane.

- Parole del vocabolario italiano, iniziale maiuscola, 2 cifre e 1 carattere speciale (tutto attivabile/disattivabile)
- Lunghezza minima regolabile (default 12)
- Vocabolario di oltre 1.400 parole: parole comuni, nomi di persona, città, nazioni, luoghi storici, pesci, canzoni, cantanti, frutta, verdura e piante
- Tasto **Copia** negli appunti
- Generazione sicura (`crypto.getRandomValues`), tutto in locale, funziona offline

## Installazione su iPhone
1. È pubblicata su GitHub Pages: https://iltacc.github.io/parolina/
2. Apri il link con Safari → Condividi → **Aggiungi a schermata Home**.
