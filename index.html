Prima volta? Configura in 1 minuto
  1. Apri Note e crea una nota chiamata Password (non bloccata).
  2. Apri Comandi Rapidi → tocca + → rinomina il comando in Parolina (esattamente così).
  3. Aggiungi l’azione Aggiungi a nota (o “Aggiungi alla nota”).
  4. Come testo scegli Input comando rapido, come nota scegli Password.
  5. Fatto. Da ora il pulsante giallo aggiunge ogni password in fondo alla stessa nota. La prima volta iOS potrebbe chiederti il permesso: tocca Consenti sempre.
